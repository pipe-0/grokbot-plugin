# Changelog

## 1.0.0

- Initial release: hosted pipe0 MCP server (`https://api.pipe0.com/v1/mcp`) with OAuth sign-in, plus a `pipe0` skill that routes sign-in problems to Authenticate instead of API fallbacks.
- Ships manifests for Grok Build (`.grok-plugin/`) and for Grok Bot and Cursor via the Cursor Marketplace (`.cursor-plugin/`).
